# Бонус-уровни: карта

Бонус-модули лежат в папке `bonus/` и отличаются от основной программы по смыслу и оформлению.
Основная программа учит алгоритмам и структурам данных. Бонус добавляет то, что нужно разработчику
**кроме базового Python**: инженерные привычки, мышление и работу с людьми.

> Статус: готовы b01 ([bonus/b01-pro-tools](../bonus/b01-pro-tools/README.md)) и b02 ([bonus/b02-clean-code](../bonus/b02-clean-code/README.md)), b03 в плане.

## Как бонус отличается от основы

| Что | Основная программа | Бонус-уровни |
|---|---|---|
| Папка | `m01-search` … `m08-graphs` | `bonus/b01-…`, `bonus/b02-…`, `bonus/b03-…` |
| Шаблон | `_template/` | `_template_bonus/` |
| Баннер в README | нет | `> [!IMPORTANT]` «Бонус-уровень, нужны модули 1–8» |
| Метки заданий | нет | 🛠 Hard · 🧠 мышление · 🤝 с людьми |
| Таблица прогресса | раздел «Основная программа» | раздел «🚀 Бонус-уровни» |
| Проверка шаблона | основные правила | + баннер, метки, «Образец ответа» для заданий 🤝 |

## Метки навыков

| Метка | Группа | Как проверяется |
|---|---|---|
| 🛠 | **Hard skills**: Python-инструменты, рефакторинг, type hints | pytest |
| 🧠 | **Мышление**: инженерный подход, аналитика, стратегия, системность, внимание к деталям | pytest, если ответ однозначен; иначе образец и критерии |
| 🤝 | **Работа с людьми**: ревью, объяснять решения, обратная связь, оценка сроков | только образец ответа и критерии (честно: тестами это не проверить) |

## Модули

| Модуль | Релиз | 🛠 Hard | 🧠 Мышление | 🤝 С людьми |
|---|---|---|---|---|

## Форматы заданий для 🧠

| Навык | Тип задания | Автопроверка |
|---|---|---|
| Инженерный подход | «Оптимизируй функцию»: сначала замерь, потом улучшай | решение быстрее порога и по-прежнему верно |
| | «Декомпозиция»: большую функцию разбить на части с заданными именами | тесты на каждую часть |
| Аналитический склад ума | «Найди причину»: найти входные данные, ломающие программу | тест подаёт найденные данные |
| | «Прочитай замеры»: определить сложность по таблице времени | проверка выбора |
| Стратегическое мышление | «Выбери структуру данных» по описанию задачи | проверка выбора, обоснование по образцу |
| | «Что будет при росте ×100» | функция выбирает алгоритм по размеру входа |
| Внимание к деталям | «Найди три ловушки в коде» (изменяемый аргумент, `==` вместо `is`, пустой ввод) | тесты |
| Умение учиться | применить новую функцию стандартной библиотеки по документации | тесты |

## Как создать бонус-модуль

1. Скопировать `_template_bonus/` в `bonus/bNN-name/` (латиница и дефисы).
2. Переименовать `solutions/bNN_name.py` по имени папки (дефис → подчёркивание).
3. Заполнить README: баннер, таблица «Что нужно, кроме Python», задания с метками.
4. Проверить: `python tools/check_template.py`, `PRACTICUM_TARGET=solutions pytest`, `ruff check .`, `mypy bonus/bNN-name/solutions/*.py`.
