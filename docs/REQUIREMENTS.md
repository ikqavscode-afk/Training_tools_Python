# Требования

Версия 0.2 · 2026-11-10

## 1. Принятые решения

| Вопрос | Решение |
|---|---|
| Формат | Только репозиторий на GitHub, без сайта и приложения; интерактив — средствами GitHub (Codespaces, Actions) |
| Языки | Только русский |
| Задания «найди ошибку» | Пишутся заново, с придуманными ошибками |
| Вводный модуль | Не делаем |
| Название | Решим позже (`<repo>`) |
| Роль pytest | Механизм проверки заданий |
| Расширения | После v1.0: «Как это делают профи» и «Качество кода» |

## 2. Цели

| # | Цель | Критерий |
|---|---|---|
| G1 | Повторить и закрепить пройденное | 8 модулей, задания по всем темам практических работ |
| G2 | Портфолио разработчика | Чистый репозиторий, зелёный CI, понятный README, таблица навыков |
| G3 | Другие могут практиковаться | Открыть в Codespaces и решать без установки |

## 3. Аудитория

- **Новичок** (учит Python пару месяцев): нужны простые слова и малые шаги.
- **Готовящийся к собеседованию**: нужны быстрая теория и чёткие задачи.
- **Рекрутер/ревьюер**: за 2 минуты понять, что сделано и каким стилем.

## 4. Границы

**Входит:** 8 модулей, теория, задания с pytest-проверкой, подсказки, эталоны, `demo.py`, Codespaces, GitHub Actions, шаблоны Issues/PR, документация.
**Не входит:** сайт, приложение, редактор в браузере, анимации, XP/значки, английский язык, аккаунты, БД/веб/API/архитектура.

## 5. Функциональные требования

Приоритет: **M** — обязательно, **S** — желательно.

### Контент
| ID | Требование | П |
|---|---|---|
| FR-01 | Модуль = папка с `README.md`, `exercises.py`, `test_exercises.py`, `solutions/`, `demo.py` | M |
| FR-02 | README модуля: что это, зачем, 2–5 коротких карточек теории (≤ 80 слов), схема Mermaid, «А знаете?» | M |
| FR-03 | У каждого задания ≥ 3 подсказки по нарастанию, спрятанные в `<details>` | M |
| FR-04 | Каждое задание имеет эталон в `solutions/` | M |
| FR-05 | Объяснения простыми словами, метафоры, игровые вставки, расшифровка терминов | M |
| FR-06 | Типы заданий: допиши пропуск, напиши с нуля, найди ошибку, предскажи вывод, сравни скорость | M |
| FR-07 | Каждый факт — проверенный, с ссылкой на источник | M |
| FR-08 | Глоссарий терминов | S |

## 6. Нефункциональные требования

| ID | Область | Требование |
|---|---|---|
| NFR-01 | Читаемость | Текст ≤ 80 слов на карточку, без жаргона без расшифровки |
| NFR-02 | Качество кода | Ruff без ошибок, Mypy на `solutions/`, type hints и docstrings, PEP 8 |
| NFR-03 | Воспроизводимость | `pip install -e .[dev]` и `pytest` работают на чистой машине; Python 3.11+ |
| NFR-04 | Скорость | Весь набор тестов ≤ 60 с |
| NFR-05 | Сопровождаемость | Новое задание добавляется в одной папке по шаблону |
| NFR-06 | Доступ | Работает без регистрации и без установки (Codespaces) |
| NFR-07 | Лицензии | MIT; зависимости совместимы |
| NFR-08 | Безопасность | Секретов в репозитории нет; Dependabot; Actions с минимальными правами |
| NFR-09 | Авторское право | Условия заданий не копируются из курса |

## 7. Допущения

- Аудитория знает базовый Python: переменные, циклы, функции, списки, словари, простые классы.
- Codespaces доступен бесплатно в рамках лимита GitHub; запасной путь — локальный запуск.
- Один разработчик; работа идёт короткими недельными спринтами.

## 8. Критерии релизов

- **v0.1:** модули 1–4, CI, Codespaces, шаблон модуля.
- **v1.0:** все 8 модулей, таблица прогресса, Quality gates, README-витрина, вычитка.
- **v1.1:** «Как это делают профи». **v1.2:** «Качество кода».

## 9. Риски

| Риск | Мера |
|---|---|
| Много контента | Строгий шаблон, 5 SP на модуль, срезаем глоссарий и схемы первыми |
| Лимиты Codespaces | Инструкция локального запуска в README |
| Решения в открытом доступе (спойлеры) | Папка `solutions/` с предупреждением, подсказки по уровням |
| Ошибки в фактах | Источник у каждого факта, вычитка в G3 |
