# Глоссарий

Простые определения терминов из модулей. В последнем столбце — модуль, где термин встречается впервые.

## Общее

| Термин | Что это | Модуль |
|---|---|---|
| Алгоритм | Пошаговая инструкция для решения задачи. | 1 |
| Исключение | Сигнал об ошибке в программе, например `ValueError` или `IndexError`. | 3 |
| Бинарный поиск | Поиск в отсортированном списке: каждый шаг отбрасывает половину. | 1 |

## Скорость алгоритмов

| Термин | Что это | Модуль |
|---|---|---|
| O(1) | Время не зависит от размера данных. | 6 |
| O(log n) | Время растёт очень медленно: при удвоении данных добавляется один шаг. | 1 |
| O(n) | Время растёт вместе с размером данных: вдвое больше данных, вдвое дольше. | 1 |
| O(n log n) | Скорость хороших сортировок: MergeSort и QuickSort в среднем. | 4 |
| O(n²) | Время растёт как квадрат размера: вдвое больше данных, вчетверо дольше. | 2 |

## Рекурсия, стек и очередь

| Термин | Что это | Модуль |
|---|---|---|
| Рекурсия | Приём, когда функция решает задачу, вызывая саму себя для меньшей части задачи. | 3 |
| Базовый случай | Условие, при котором рекурсия останавливается и больше не вызывает себя. | 3 |
| Рекурсивный случай | Шаг, где функция вызывает саму себя для задачи поменьше. | 3 |
| Стек | Структура, где первым выходит тот, кто пришёл последним (LIFO). | 3 |
| Стек вызовов | Стопка незавершённых вызовов функций, из которой Python берёт верхний. | 3 |
| LIFO | «Последним пришёл — первым ушёл». Так работает стек. | 3 |
| Очередь | Структура, где первым выходит тот, кто пришёл раньше (FIFO). | 5 |
| FIFO | «Первым пришёл — первым ушёл». Так работает очередь. | 5 |
| `deque` | Двусторонняя очередь из `collections`: быстро добавляет и снимает с обоих концов. | 5 |

## Сортировки

| Термин | Что это | Модуль |
|---|---|---|
| Опорный элемент | Элемент, вокруг которого QuickSort делит список на меньшие и большие. | 4 |
| `partition` | Разбиение списка вокруг опорного элемента: слева не больше, справа больше. | 4 |
| Слияние (`merge`) | Объединение двух отсортированных списков в один отсортированный. | 5 |

## Деревья

| Термин | Что это | Модуль |
|---|---|---|
| Дерево | Структура из узлов, где у каждого узла может быть несколько потомков. | 7 |
| Узел | Элемент дерева: хранит значение и ссылки на потомков. | 7 |
| Корень | Самый верхний узел дерева. | 7 |
| Лист | Узел дерева без потомков. | 7 |
| BST | Бинарное дерево поиска: слева значения меньше, справа больше. | 7 |
| Обход дерева | Посещение всех узлов в определённом порядке. | 7 |
| DFS | Обход в глубину: идём вниз до конца, потом возвращаемся. | 7 |
| BFS | Обход в ширину: сначала все ближние вершины, потом дальние. Нужна очередь. | 7 |
| Высота узла | Длина самой длинной цепочки узлов вниз от него, считая сам узел. | 7 |
| Баланс узла | Высота левого поддерева минус высота правого. Для AVL допустимы −1, 0 и 1. | 7 |
| Балансировка | Перестройка дерева, чтобы оно не вытягивалось в цепочку. | 7 |
| Поворот | Перекидывание связей у трёх узлов дерева, чтобы выровнять высоту. | 7 |
| AVL-дерево | Дерево поиска, которое само следит за балансом с помощью поворотов. | 7 |
