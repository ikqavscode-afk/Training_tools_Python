# 🐍 Python: алгоритмы и структуры данных — практикум

> Репозиторий-практикум. Название появится позже: `<repo>`.

Набор небольших упражнений по алгоритмам и структурам данных на чистом Python.
Каждая тема — это короткое объяснение, задания с автопроверкой, подсказки, готовое решение и «интересный факт».
Ничего устанавливать не нужно: нажмите **Open in Codespaces** — и редактор с Python откроется в браузере.

## Зачем это

| Для кого | Что даёт |
|---|---|
| Новичок в Python | Закрепить циклы, функции, списки, классы на понятных задачах |
| Готовящийся к собеседованиям | Быстро повторить базу: поиск, сортировки, хэши, деревья, графы |
| Автор | Показать, что пройдено и закреплено, в виде аккуратного репозитория |

## Как пользоваться (3 шага)

1. **Откройте** репозиторий в Codespaces (кнопка «Code → Codespaces») или клонируйте локально.
2. **Выберите модуль** и прочитайте его `README.md` (5 минут).
3. **Допишите код** в `exercises.py` и запустите проверку:

   ```bash
   pytest m01-search
   ```

Зелёные тесты — задание выполнено. Застряли? Откройте подсказку 1, затем 2, затем 3. Решение лежит в `solutions/`, смотреть его — последний шаг.

Хотите, чтобы проверку делал GitHub? Сделайте **fork**, запушьте решение — во вкладке **Actions** появится таблица, что выполнено.

| № | Тема | Что тренируем |
|---|---|---|
| 1 | Поиск | линейный и бинарный поиск, O(n) и O(log n), замер времени |

## Что внутри модуля

```
m03-recursion/
├─ README.md          что это и зачем · теория карточками · игра · факт
├─ exercises.py       заготовки с TODO
├─ test_exercises.py  автопроверка с понятными сообщениями
├─ solutions/         готовые решения (спойлеры!)
└─ demo.py            запуск «что получилось» с выводом
```

Типы заданий: допиши пропуск · напиши с нуля · найди ошибку · предскажи вывод · сравни скорость.
